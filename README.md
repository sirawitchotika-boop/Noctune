# Noctune

Your music, without the noise.

An independent, offline-first Android music player under development. This repository is separate from [GT SoundMaster](https://github.com/sirawitchotika-boop/Music-Player-Local); the original app and its data remain untouched.

Current state: repository bootstrap. Phase 0–1 implementation is proposed through a reviewable pull request. No release or phone installation is authorized.
